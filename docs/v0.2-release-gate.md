## 3. Gate 暴露的 5 个问题

### ⚠️ Issue 1: **表格缺 authors 列**(高)

`render_lineage()` (line 177-198) Markdown 表格只有 5 列:
```
| Citekey | 标题 | 年份 | 引用 | DOI 状态 |
```

**没有 authors 列**。但 S2 返回的 `externalIds.authors` 是有数据的(`_load_local_corpus` line 267 明确生成 `[{"name": ...}]`)。

**影响**: 论文溯源/可读性降级,人工核对 citekey 时无法快速识别同名异作。
**修复方向**: render_lineage 加一列 "作者", 取 first author + "et al." (类似 IEEE 风格)。

### ⚠️ Issue 2: **标题被截到 60 字**(中)

`touvron2020` 实际标题是 "Training data-efficient image transformers & distillation through attention",产物里被截到 "Training data-efficient image transformers & distillation th"。

**影响**: 论文辨识度低,跨表对比时容易误判。
**修复方向**: 标题截到 80-100 字;或者不截, 改用 CSS/HTML `text-overflow` 风格(不适用于纯 Markdown)。

### ⚠️ Issue 3: **Crossref 假阳性**(中)

`dao2022 (FlashAttention)` 的 DOI `10.52202/068431-1189` 被 Crossref 标记 ✅, 但这是预印本编号不是真 DOI。Crossref 反查对预印本 archive 的 DOI 接受过于宽松。

**影响**: fact_check_status 虚高, 真正的 DOI 验证不准。
**修复方向**: crossref_verify.py 区分 "official publisher DOI" vs "preprint server DOI"; 或者只接受 Crossref 主流 publisher (Elsevier/Springer/IEEE/ACM) 的命中。

### ⚠️ Issue 4: **DOI 错配**(中)

`velickovic2017 (Graph Attention Networks)` 实际 DOI 是 `arXiv:1710.10903` (preprint), Crossref 反查返回的 `10.17863/CAM.48429` ❌ (Cambridge repository 的另一个 GAT 相关物)。S2 拿到的 `externalIds.DOI` 字段填错。

**影响**: Crossref 假阴性 — 明明 DOI 在 S2 端, 反查失败。
**修复方向**: 优先用 S2 的 `externalIds.DOI` 字段, 不行再 fallback 到 arXiv ID 反查。

### ⚠️ Issue 5: **_index.csv 完全不参与合并**(高)

10 篇论文全部未与本地 `_index.csv` 命中, 全部生成了合成 citekey (`[[velickovic2017]] (合成)`)。

**影响**: 丢失了 1.4 万本地论文元数据的引用关联机会, bootstrap 产物游离于 vault 之外。
**修复方向**:
- 选项 A: bootstrap 时先用 `title` 模糊匹配本地, 失败再用 DOI
- 选项 B: 让 v0.3 先建 `obsidian-vault/Literature/` 镜像 `_index.csv`, bootstrap 直接读 Literature/ 而非 _index.csv
